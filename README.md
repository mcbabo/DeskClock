# DeskClock

A replacement for the old clock app (`com.android.deskclock`). This app features the main
functionality of the clock app but with the current Material 3 (Expressive) design guidelines.

### Disclaimer

The project is currently under development and is not yet suitable for a replacement of the default
clock app.

## Features

Under development:

- Alarms

In future:

- Timezone based clocks
- Timer
- Stopwatch
